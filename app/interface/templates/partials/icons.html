{# Inline SVG icon set. Deliberately tiny: the interface uses icons only where one carries meaning (the brand mark, the theme toggle, the mobile menu). Decorative icons were removed - they made every list look like a dashboard. Kept as a Jinja macro rather than an icon font or sprite file so icons inherit `currentColor`, need no extra network request, and stay inside the `script-src 'self'` content security policy. Usage: {% raw %}{{ icon('pulse') }}{% endraw %} {% raw %}{{ icon('shield', 'my-extra-class') }}{% endraw %} Every path is drawn on a 24x24 grid with no fill; stroke width and colour come from the parent (.icon-box, .btn) via CSS. #} {%- set ICON_PATHS = { 'pulse': '', 'sun': '', 'moon': '', 'menu': '', 'close': '' } -%} {% macro icon(name, extra_class='') -%} {%- endmacro %}
