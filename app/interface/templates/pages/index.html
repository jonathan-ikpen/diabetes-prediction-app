{# ------------------------------------------------------ ARCHITECTURE -- #}
Hybrid architecture

Numbers from the model, meaning from the guidelines

A statistical model can produce a number but cannot explain it safely. A language model can explain but should not be trusted to recall clinical thresholds. This system separates the two jobs.
